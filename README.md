# sales-performance-dashboard
Designed an interactive Power BI dashboard to monitor and evaluate the performance of sales employees against targets across regions, products and time.

Overview

This project was developed to demonstrate how a company can track sales team performance in one place. The objective was to build a clear, easy-to-use dashboard that helps managers see who is meeting targets, where revenue comes from, and how performance changes over time.

Note: The dataset is sample (simulated) data created for demonstration purposes. It does not represent any real company.

# Dataset
Employees: 12 sales representatives with region, manager and hire date
Sales: 1,000+ orders (Jan–Oct 2026) with product, units, revenue and deal status (Won/Lost)
Targets: monthly revenue target per employee

# Analysis
The analysis included:

- Data cleaning and data type correction in Power Query
- Data modeling (star schema with a shared Calendar table)
- KPI definition using DAX measures
- Target vs. actual revenue comparison
- Employee ranking and performance gap identification
- Product and regional revenue breakdown

# Dashboard

An interactive dashboard was developed to present key insights, allowing managers to:

- Monitor KPIs (revenue, target achievement, win rate, average deal size)
- Rank employees by revenue
- Compare revenue against target month by month
- Identify underperformers with colour-coded results (green / amber / red)
- Filter by region, manager and date range
