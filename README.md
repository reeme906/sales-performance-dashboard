# sales-performance-dashboard
Designed an interactive Power BI dashboard to monitor and evaluate the performance of sales employees against targets across regions, products and time.

Overview

This project was developed to demonstrate how a company can track sales team performance in one place. The objective was to build a clear, easy-to-use dashboard that helps managers see who is meeting targets, where revenue comes from, and how performance changes over time.

Note: The dataset is sample (simulated) data created for demonstration purposes. It does not represent any real company.
